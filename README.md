# CampusDeals

CampusDeals is a simple student-discount and local deals web app MVP.

## Tech Stack
- Next.js
- React
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Features
- Student-focused promo cards
- Search/filter style landing page
- Store submission form
- Responsive layout for mobile and desktop

## Notes
This is a demo MVP focused on validation and launch speed rather than production-grade backend features.
